# Support

## Seeking Help

If you encounter an issue or have a question about Rayan, please:

1. **Check the Documentation:** Read the `README.md` and explore the `rayan-master-document.md`.
2. **Search Issues:** See if someone has already reported the issue on GitHub.
3. **Open a Discussion:** For feature requests and general questions, use GitHub Discussions.
4. **File an Issue:** For reproducible bugs, open a new Issue using the provided templates.

## Security Vulnerabilities

Please **do not** file a public issue for security vulnerabilities. Instead, follow the instructions in our [SECURITY.md](SECURITY.md) to report it responsibly.
