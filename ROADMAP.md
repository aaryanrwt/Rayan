# Rayan Roadmap

This document outlines the high-level roadmap for Rayan. (Note: Everything mentioned in the `rayan-master-document.md` is currently fully implemented in the RC-1 release).

## Future Explorations (Post v1.0)
- **Native Windows Support:** Expanding beyond Nix-on-WSL to support native Windows package management natively via the ASG.
- **WASM Browser Compilation:** Running the Rust `rayan-core` and `rayan-compiler` directly in the browser for the `rayan-web` dashboard.
- **Hardware Integration Expansion:** Deepening the hardware telemetry checks to auto-optimize kernel parameters based on detected CPU cache layouts.
