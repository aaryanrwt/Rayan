# Security Policy

## Supported Versions
We currently support the `main` branch and the latest stable release of Rayan for security updates.

## Reporting a Vulnerability
We take the security of Rayan very seriously. If you discover a security vulnerability within Rayan, please do not disclose it publicly.

Instead, please send an email to the core maintainers via GitHub's private vulnerability reporting feature. We will promptly review and address all reports.

### What to include in your report:
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Proposed solution (if any).

We will try to acknowledge receipt of your vulnerability report within 48 hours and will strive to send you regular updates about our progress. If a fix is implemented, we will coordinate with you to publish a security advisory.
