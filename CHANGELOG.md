# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- **Rayan Compiler**: Natively supports `compile_to_darwin` and `compile_to_oci`.
- **Rayan Enterprise**: Policy-as-Code engine and CycloneDX SBOM generation.
- **Client Ecosystem**: Scaffolding for Tauri `desktop` GUI, `extensions/vscode`, and `extensions/emacs`.
- **Neuro-Agent**: Hardware telemetry blocking and Voice command transcription interfaces.

### Changed
- Converted core Rust workspace to support 13 independent crates.

## [0.1.0] - 2026-08-01

### Added
- Initial release of the Rayan Core Engine.
- Literate Markdown parsing and deterministic Nix compilation.
- Anthropic Claude-3 RAG Planner integration.
